## 🌟 Propósito del Sitio

Aplicación web oficial de **FVision**, consultoría de ingeniería orientada a transformar procesos manuales, documentos dispersos y silos de información en sistemas productivos para empresas medianas y en crecimiento, entregados en ciclos de alcance cerrado de **2 a 4 semanas**.

---

## 🏛️ Estructura de Contenidos B2B

1. **Áreas de Práctica Oficiales:**
   * **Ingeniería de Datos & Inteligencia Operativa (BI / ETL):** Pipelines automatizados de extracción, limpieza y consolidación de ERPs, CRMs y hojas de cálculo.
   * **Automatización de Procesos & Agentes de IA Operativos:** Flujos de backoffice e integración de sistemas bajo reglas estrictas con supervisión humana (*Human-in-the-Loop*).
   * **Procesamiento Documental Inteligente (OCR) & Visión Computacional:** Lectura estructurada de facturas, remitos y comprobantes fiscales (validación QR AFIP/ARCA) e inspección visual en línea operativa.
   * **Modelos Predictivos & Sistemas de Conocimiento Privado (RAG):** Pronóstico de demanda, prevención de *churn*, *scoring* comercial y repositorios de consulta documental en infraestructura privada con cero fuga de datos.

2. **Casos de Aplicación Corporativa:**
   * Conciliación Documental & Auditoría Fiscal Automatizada.
   * Mesa de Entradas Inteligente & Triage Operativo.
   * Repositorio de Conocimiento Técnico & Legal en Entorno Privado.
   * Tablero de Rentabilidad Unitaria & Pronóstico de Demanda.

## 🛠️ Stack Tecnológico

* **Frontend:** React 19, TypeScript, Tailwind CSS v4, Framer Motion, Lucide Icons
* **Build Tool:** Vite 6
* **Hosting:** GitHub Pages (`/FVision-Builders/`)
* **Testing:** Vitest & Testing Library

## 🚀 Desarrollo y Despliegue

```bash
# Instalar dependencias

# Iniciar servidor de desarrollo

# Compilar versión de producción
npm run build

# Ejecutar pruebas
```
